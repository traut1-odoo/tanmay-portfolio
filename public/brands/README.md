# Brand artwork

Downloaded October 15, 2026. These marks identify tools used in the portfolio's work, not sponsors or endorsements. Each displayed mark links to its brand's homepage. Artwork remains owned by its respective brand.

| `shipstation.svg` | [ShipStation official documentation asset](https://docs.shipstation.com/static/logos/shipstation-logo.svg) |
| `claude.svg` | [Claude homepage](https://claude.com), header's `ClaudeWordmark` SVG |
| `avalara.svg` | [Avalara homepage asset](https://s7d1.scene7.com/is/content/avalara/avalara-logo) |

Odoo's surrounding SVG canvas was trimmed to its artwork bounds for consistent optical sizing. Paths and supplied colors are unchanged. Claude's page-specific class was removed. ShipStation and Claude use a white CSS silhouette in dark mode; all geometry and aspect ratios are preserved. Other dark variants are supplied brand artwork. SVGs are local files, with no external resource references or scripts.
